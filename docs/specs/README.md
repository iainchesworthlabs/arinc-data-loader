# The standards

| File | What |
| --- | --- |
| `665-3.pdf` | ARINC Report 665-3, Loadable Software Standards |
| `615A-3.pdf` | ARINC Report 615A-3, Software Data Loader Using Ethernet Interface |

These are third-party documents, published by Aeronautical Radio, Inc. They are
**not** covered by this project's licence and may not be redistributable, so the
PDFs are not in the repository: `.gitignore` excludes them. Put your own copies
of the two files above in this directory to follow the code's citations (see
[licensing](../licensing.md#the-standards)). Section numbers in the code and in
the tests refer to these editions.
