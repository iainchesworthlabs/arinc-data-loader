# The states the licence library knows, one row for each case: which test licence, when and where it is judged,
# and the state and reason it is in. The files are made again by tests/licence/make_test_licences.py from the
# requests in tests/licence/data/requests, signed with the throwaway test key (RFC 8032, test 1) that no program
# accepts; a test that judges them passes that key in. Each row is the same as
#
#   adl_licence_owner verify --test <file> --now <now> [--latest-seen <t>] [--computer <name>] [--revocations <list>]
#
# Columns, separated by white space, `-` for "not given":
#
#   file  now  latest_seen  computer  revocations  state  reason
#
# The state `none` is the absence of a file, so its row has no file. Anything after a row's last column is a
# note. The states and reasons are the words of adl::licence (state_name, reason names).

# file                  now                   latest_seen           computer    revocations        state          reason
-                       2026-06-01T00:00:00Z  -                     -           -                  none           no_licence

expiring.adllic         2026-11-20T12:00:00Z  -                     -           -                  expiring       ok               10 days left
grace.adllic            2026-03-10T00:00:00Z  -                     -           -                  grace          ok               the 28 days after the end
expired.adllic          2026-06-01T00:00:00Z  -                     -           -                  expired        expired
