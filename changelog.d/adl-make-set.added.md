**A command that makes a media set from a description file.** `adl_make_set make` reads a JSON file that names the files, the part numbers, the number of members, the check value types, a batch and one or more loads, makes the media set by the same rules as the generator's window, reads it back and checks it with the loader's own check, and only then puts it in place. The same description and files give the same bytes on every run and on every desktop. `adl_make_set verify` checks a media set folder, and `adl_make_set inspect --json` writes what a media set holds as one JSON document. The generator's window and the command now make a set with the same code. See [Command line and exit codes](../docs/user-guide/command-line.md#adl_make_set) and [the description file](../docs/file-reference.md#the-media-set-description).
