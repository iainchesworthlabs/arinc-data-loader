**The development package can record an operation and write the record as a file.** `adl::loader_core` has a record of one ARINC 615A operation (the target, the times, how it ended, the loads, the configuration an Information operation read, the files a download received and the log), a recorder that fills it from what the engine reports, with the same sentences and the same decisions about what is logged as the window's log, and a writer that turns it into one JSON file with a fixed layout. The window does not write the file yet. See [the operation record](docs/file-reference.md#the-operation-record).
