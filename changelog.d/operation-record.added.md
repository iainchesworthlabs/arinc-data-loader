**The development package can record an operation.** `adl::loader_core` has a record of one ARINC 615A operation (the target, the times, how it ended, the loads, the configuration an Information operation read, the files a download received and the log) and a recorder that fills it from what the engine reports, with the same sentences and the same decisions about what is logged as the window's log. The window does not use it yet. See [Using the libraries](docs/libraries.md).
