**`adl_load serve` runs operations on several targets at once from one loader port.** Every `adl_load` listens on the loader's port, 59, so two of them on one computer cannot both have it, and a real target writes to 59. `adl_load serve` is one process that holds the port once. It reads requests on standard input, one line each with the fields separated by a tab (`run`, `cancel` and `stop`), starts each `run` as an `information`, `upload` or `download` operation, and writes the events of each operation as JSON lines that carry its `id`. One address has one operation at a time, up to 64 operations run at once (`--max-operations`, 8 by default), and a request that cannot be started is answered with a `request_refused` event. It has no plan, retries, schedule or report: the program that drives it keeps those. Running `adl_load` for one operation works as before. See [the command adl_load](docs/load-command.md#serve-one-loader-several-targets).
