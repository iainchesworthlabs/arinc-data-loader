**A platform can be built from a directory outside the repository.** Configure with `-DADL_TARGET_PLATFORM=<name> -DADL_PLATFORM_DIR=<directory>` and the build takes the platform's `platform.cmake` and its sources from that directory, so a port to another operating system can be kept in a repository of its own and tried without a fork. It can use the shared POSIX sources and the interface headers of this repository without copying them. Without `ADL_PLATFORM_DIR` nothing is different. See [Building](docs/building.md#a-platform-from-another-directory) for an example, and [Platform abstraction](docs/platform-abstraction.md#a-platform-kept-outside-the-repository) for what is and is not checked for such a platform.
