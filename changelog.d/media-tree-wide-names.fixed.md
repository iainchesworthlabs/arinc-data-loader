**A media set folder with a file named outside the Windows code page is refused, not a crash.** On Windows, a file or folder inside a member folder whose name has a character the system's code page has no letter for (Japanese on a Western system, for one) made the code that reads a media set folder throw an error that nothing in the programs catches, so the program ended. The folder is now refused, as it is for any other name a media set cannot hold (a colon, a trailing dot), and the message names the file. [Files the programs read and write](../docs/file-reference.md) says what a media set folder may hold.
