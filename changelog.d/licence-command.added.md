**A command-line program, `adl_licence`, shows and manages the licence on a computer.** `adl_licence show` prints the edition, the licence in force and every licence file the programs find. `adl_licence import <file>` copies a licence file, or a signed list of withdrawn licences, into your licence folder, `adl_licence remove <name>` takes one out of it, and `adl_licence verify <file>` says what a program would make of a file and keeps nothing. It reads and writes the same files in the same folders as the three programs with windows (`ADL_SETTINGS_DIR` moves them), it is for a computer with no display and for scripts, it uses no network, and `show` and `verify` write nothing. It is in the release packages beside `adl_write_payloads`. See [the command line](docs/user-guide/command-line.md#adl_licence).
