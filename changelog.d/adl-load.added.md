**A new command-line program, `adl_load`, runs one operation on one target with no window.** `adl_load find`, `information`, `upload` and `download` do what the loader's window does for one target: an upload reads and checks the media set first and refuses one that cannot be read, a download writes the files into a folder of its own, and a download can take all the files the target lists or the ones named. Each step is written to standard output as a JSON line (`--json`) or as a plain line, `--record` writes the operation record as a file, and the exit code says how it ended (0 completed, 1 failed, 2 wrong usage, 3 the media set could not be read or changed, 4 the target did not answer, 5 a local error). It is in the packages beside the other programs, and its text is English only. A media set, a download folder or a record file can be in a folder named with any characters on every system. See [the command adl_load](docs/load-command.md).
