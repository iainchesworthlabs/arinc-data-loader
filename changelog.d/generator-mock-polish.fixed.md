The media set generator no longer greets a new operator with alarms: a fresh form says NOT STARTED, a
field shows what is wrong with it only once you have been in it (or you pressed Generate on an incomplete
form, which now marks what is missing), and the state is named once, in the header. The file table's
headers line up with its rows at any window width, the empty state is centred, and a generation you
cancel ends as CANCELLED rather than FAILED. The mock target shows an armed fault injection as a chip in the
header and the footer that scrolls to it, moves its progress bar only while it works, makes Stop the main
button while it serves, and its error is a banner. See [the generator](docs/media-gen.md) and
[the mock target](docs/mock-target.md).
