**`adl_mock` runs the mock target with no window.** It is a command-line program for test rigs and CI jobs: the target's identity, folders, ports and faults are options, and it writes one line, or with `--json` one JSON object, for each event (it started, an operation began, an upload arrived, an operation ended, it stopped). It stops after a number of operations or of seconds, and has its own exit codes. It also has two faults the window has no control for: refusing with status 0x1002, and an initialization file of invalid structure. It is a mock, not a real target. See [Command line and exit codes](docs/user-guide/command-line.md#adl_mock) for its options, exit codes and messages, and [the mock target](docs/mock-target.md#the-command).
