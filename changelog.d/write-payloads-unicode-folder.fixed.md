**`adl_write_payloads` writes into a folder with any characters in its name on Windows.** A name with a character outside the system's code page (Japanese on a Western system, for one) reached the program with question marks in it, so the program failed or wrote into a folder with another name. It now reads its arguments as Unicode, and prints the folder it wrote to as UTF-8. Linux and macOS were not affected. [The rule for command-line programs](../docs/architecture.md#command-line-programs) says how a program gets its arguments.
